# Inspect the model

- Wireframe shows the triangle edges. Normals draws the vertex normals in cyan. Bounds draws the bounding box and shows its size.
- Skeleton draws the bones of a skinned model in orange. It is off for models without bones.
- The Model panel lists the format and version, the program that wrote the file, and the counts. Copy puts them on the clipboard.
- Textures lists every texture file the model uses with its size. A file that is not next to the model is listed as missing, by name.
